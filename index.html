Task Manager

Same features in every version: add tasks with priority and due date, complete and delete, All / Active / Done filters, task counter, List and Board views, overdue highlight, dark and light mode. Only the design changes.

Version 1: CleanSoft indigo, rounded corners, simple.
Version 2: BrutalistThick borders, hard shadows, monospace.
Version 3: GlassGradient background, frosted panels, pill buttons.
